Это локальный редактор, а не закрытая панель авторизации. Любой посетитель может составить черновик, но опубликовать его может только пользователь с правом записи в репозиторий GitHub. Не добавляйте ФИО студентов, пароли, оценки и закрытые материалы.

4. Публикация

Сначала сохрани редактируемое задание или объявление в черновике. Затем скачай файл content.json и загрузи его в корень репозитория через браузер. Если Android добавил к имени «(1)», переименуй файл обратно в content.json.

Открыть загрузку GitHubПроверить Actions

Публикация произойдёт только после коммита в main и успешного GitHub Actions. Расписание и индивидуальные варианты не редактируются здесь. Черновики хранятся отдельно от личного прогресса.
