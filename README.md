# knitu-studyhub
KNITU StudyHub — неофициальный цифровой помощник студентов КНИТУ. Расписание занятий, персональные учебные задания, варианты по зачётной книжке, чек-листы, дедлайны, экзамены и учебные материалы. Адаптивное PWA-приложение.

## Development

- main — stable production version.
- develop — development and testing.
- Backend: FastAPI + MySQL 8.4 LTS.
- Planned authentication: MAX.
- Mobile development: Spck Editor.
